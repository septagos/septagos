# Septagos

I work on Deep Tech, autonomous AI systems and the infrastructure behind machine-to-machine interactions.

I'm particularly interested in how autonomous agents can identify themselves, interact with other systems, make decisions and exchange value without relying on constant human intervention.

## What I'm working on

My main project is [Subcento](https://subcento.alterfield.com), a verification layer for x402 payments on Base.

Before an AI agent signs a USDC payment authorization, Subcento allows it to check what the payment route actually does. This includes the receiving contract, token behaviour and the destination of the funds.

The idea is simple: an agent should have a way to inspect a transaction before committing its funds.

Subcento follows a fail-closed approach. If a payment cannot be verified, it should not proceed.

## Why I'm interested in this problem

As AI agents become more capable of acting independently, payments and interactions between machines will become an increasingly important part of the ecosystem.

But allowing an agent to execute a transaction is not the same as giving it the means to understand what it is approving.

I believe verification, identity and trust will play an important role in the development of this emerging machine economy. This is one of the areas I want to keep working on.
